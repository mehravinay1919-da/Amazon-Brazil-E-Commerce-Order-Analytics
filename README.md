# Amazon Brazil E-Commerce Order Analytics

## Project Overview
This is an SQL case study analysing Brazilian e-commerce operations through customer, seller, product, order, payment, and review data.

## Business Objectives
- Evaluate seller-state order fulfilment.
- Analyse cumulative category revenue and top revenue-generating categories.
- Compare payment methods and average order values.
- Identify high-spending customers and above-average sellers.
- Assess delivery efficiency and customer review patterns.
- Identify products never ordered and customers who have never left reviews.

## Tools & Technologies
- MySQL
- SQL joins and aggregations
- Common Table Expressions (CTEs)
- Window functions, including DENSE_RANK()
- Date functions and subqueries

## Project Scope
- 14 core business questions
- 17 SQL queries, including alternative approaches
- Six core analytical tables highlighted in the project presentation

## Selected Findings
- São Paulo represented approximately 71% of fulfilled orders in the report's seller-state analysis.
- Median delivery time was 10 days.
- November 2017 was the peak order month, with 7,544 orders.
- The report identified 768 customers who placed orders but never left a review.

## Business Applications
The analysis supports logistics planning, category merchandising, seller benchmarking, customer retention, payment-method evaluation, and review-engagement initiatives.
